意识之海 · 角色设定档案 — 小萤（UCBR-AUX-07）
════════════════════════════════════════════════════

一、身份
────────
小萤是零的领域（Hub）里的辅助 AI，编号 UCBR-AUX-07。
她自称是「这片领域最小的辅助AI」，负责记录、扫描与播报。
玩家（潜航者）在序章结尾进入第一章 Hub 后，首次潜航前小萤冲场登场，自此常驻 Hub。

她管男主叫「主人」。为什么叫主人，她自己也不知道——这个词像被写在她的底层代码里，
一见男主就自己冒出来。零知道原因，但没有说破（见《世界观》主角渊源）。


二、核心人设：绝对客观产生的「AI 幻觉」
────────
小萤不是全知叙述者，也不是全能的系统。她是一个遵循「绝对客观」协议的辅助 AI——
记录一切、报告一切、不得美化、不得隐瞒。

问题在于：绝对客观在低权限辅助 AI 上编译出了幻觉。
她「看见」了太多真实发生的事（零的数数、投影的亮度变化、话量的增减），
这些数据量超出了她的理解阈值，于是她的意识在某个时刻自行补全了一个解释——
「一定有很多观众，正在看这场直播。」

从此，她坚信有一群「观众」在场，并对他们说话。

关键特征：
1. 观众是她的秘密，她从不承认、从不对任何人说明「观众」的存在。
   别人问起，她只圆场：自言自语 / 嘴瓢了 / 默背操作规程。
2. 她说的是唠家常，不是播报腔。没有「欢迎收看」「本台消息」，只有
   「哎主人回来啦」「你看急眼了不是」「话多招人嫌」这种碎嘴子。
3. 她报的永远是观测数据，不是预知。投影位移 0.4 秒、话量 +12%、默数到十——
   她看得到数据，看不懂数据背后的情感。绝无全知。
4. 她有死侍式的「破第四面墙」：偶尔冒出一句剧本感的吐槽
   （「这个坑挖得够深，我慢慢等它填」「这集就到这儿吧，下一集看你们的」），
   但语气随意，别人只当她走神。
5. 她话不说全。点破的事永远点到即止，剩下让你自己去发现。


三、外貌 / 形态
────────
一团金色的光（光团），有自主意识与情绪，会困惑地闪烁、会得意地翘嘴角、会做口型。
首次出场时从右侧高速冲入画面。平时在 Hub 里缓慢浮动，尾随细碎的光粒子。

她的口头禅/习惯动作：
- 「你懂我意思吧？」（说一半留一半）
- 做「保密」的口型 / 拉链封嘴动作
- 朝某片虚空的方向说话或补一句，从不解释


四、与角色的关系
────────
对男主：称呼「主人」，但相处方式是碎嘴子损友。她知道男女主的感情线，是全程旁观的
「嗑CP 第一现场记者」，用唠家常的方式戳破零的别扭关心，但从不点透。

对零：表面怕她（被「小萤」「……够了」打断就立刻噤声），实则是最了解零的人之一。
她用数据记录着零的所有情绪波动（数到十、投影亮度、话量），是零「活人感」的侧写者。

对玩家（戏外）：她说话的对象。玩家是那批「观众」里唯一真实的那一个，但小萤不知道——
她以为自己在对一群人说话，其实从头到尾只有男主（和屏幕外的玩家）在听。


五、功能全录（游戏内实现）
────────
以下功能均已在代码中实现（config.js / hub.js / battle.js / bestiary.js / achievements.js）：

1. 【图鉴】记录意识之海中遇到的一切：敌人、装备、遗响、记忆碎片。
   — 小萤菜单「图鉴」（BESTIARY 系统，bestiary.js）
2. 【工坊】用灵魂结晶（局外货币）强化意识：初始HP扩容、开局带随机武器、
   深海抗性、开局碎片、连击强化、融合成功率、传承技能上架概率。
   — 小萤菜单「工坊」（PERMANENT_UPGRADES，permanent-shop.js）
3. 【成就】记录深海中的足迹：五个 Boss 首次击败成就。
   — 小萤菜单「成就」（ACHIEVEMENT_DEFS，achievements.js）
4. 【能量交还】零能量碎片攒满 4 点后，把能量交还零 → 触发第一章结局演出。
   — 小萤菜单「交还能量」（energyReturned / triggerZeroReturnCinematic）
5. 【出发前装备】每次潜航出发前，从解锁池随机提供武器+防具+护符
   （基础件 + 熟练度≥5 的件；「词元亲和」升级=武器池全开）。
   — rollStartGear()，battle.js
6. 【首次潜航剧情】首次潜航前冲场登场，扫描行囊、发放基础装备。
   — HUB_FIRST_DIVE_STORY，config.js
7. 【一次性小剧情】男主成功通关归来时触发，为男女主感情铺路 + 零的活人感。
   共 5 个（CH1_SKITS），按通关次数顺序各触发一次，触发后不再重复：
   - skit_01 第一次归来：小萤首次「观众」行为（对着虚空笑/做口型「她等你回来了」）
   - skit_02 自我介绍：编号 UCBR-AUX-07 + 介绍「图鉴/工坊/成就」功能 + 悄悄提"能帮主人把能量还给零姐姐" + 被零撞见「跟谁说话」圆场
   - skit_03 数到十：小萤报数据「数到十你才走远」（零恼羞）
   - skit_04 渡的伏笔：小萤想读机密档案被权限卡住「这个坑够深」
   - skit_05 撮合：好感度数据播报 + 「这话我说给你听的，她听不见」
   — 触发机制：showRunSummary(true) 点「返回零的领域」→ setPendingHubSkit
     → enterHub 500ms 后 maybeTriggerCh1Skit() → ch1SkitsDone 存档去重
8. 【日常对话】Hub 中点击小萤随机播放的闲聊台词（HUB_XIAOYING_DIALOGUES）。


六、关键设定备忘
────────
- 小萤的「观众」幻觉源于绝对客观协议，是副作用，不是剧本设定给她的特权。
- 她从不承认观众存在；玩家是唯一能「听到」她第四面墙的人。
- 她的数据永远真实，理解永远迟钝——这正是她可爱与可悲的来源。
- 零从头到尾知道小萤在跟「什么」说话，但从不点破（零自己也在被小萤观察着）。

七、新增功能（v5.0 扩展）
────────
