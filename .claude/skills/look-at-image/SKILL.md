# 看图（视觉辅助）

主模型（DeepSeek）纯文本看不了图。用户贴图或需要看图时，用 `.claude/tools/vision.js` 把图片转成文字描述再分析。

## 触发场景
- 用户粘贴/上传图片（截图、UI 报错图、设计稿、图表）
- 用户说"看看这张图 / 分析这个截图 / 这页面渲染正常吗"
- 排查 UI 布局/样式/渲染问题（配合 Playwright 截图）

## 步骤
1. **定位图片文件**：
   - 用户明确给了路径 → 直接用
   - 对话中出现了图片引用 → 用 Glob 在项目目录 / `~/.claude/` / 系统临时目录找最近出现的图片文件
   - 找不到 → 请用户提供图片的保存路径
2. **调用视觉模型**：
   ```
   node .claude/tools/vision.js <图片路径>
   ```
   - 默认**精简模式**（只给可见文字/关键元素/异常），省 token
   - 需要完整分析时加 `--detail`
3. **基于描述回答**：把描述整理给用户，或据此继续定位问题

## 强制约定（UI 检查）
- 检查 UI/布局/样式/渲染问题：**必须**截图 + 视觉模型看实际渲染，**禁止只读代码推断布局**
- 涉及 Playwright 截图前，先询问主人是否启用 MCP（见记忆 [[ask-before-mcp]]）
- 识图模型配置在 `.vision-env.json`（默认 GLM-4.6V-Flash 免费，可换 K2.6）
