一、设计理念
────────────
每个Boss是一个「有结构的文字存在」——不是一个巨大的单字，
而是由偏旁部首拆解而成的多部件实体。

Boss循环：入场坠落 → 拆开 → 蓄力 → 攻击 → 暴露 → 拆开 ...
玩家在蓄力期/暴露期点击攻字可造成伤害（倍率不同），暴露期1.5x最佳输出窗口。


二、Boss「憾」— 首个Boss
────────────

### 拆字机制
「憾」在战场上以两个独立部件呈现：
  - 偏旁「忄」(left) — 红色，承担近战/冲撞攻击
  - 主体「感」(right) — 暖红，承担弹幕/远程攻击
两个部件拆分后近距离漂浮，看起来仍像一个字。

### 阶段循环

  entrance(坠落动画) 「憾」从屏幕上方坠落，撞击时震碎所有战场文字
      │ 落地后2秒停顿
      ▼
  split(1.0s)   拆开漂浮，两部件微微晃动，微尘粒子环绕
      │ 渐进恢复：每2词/周期缓慢补回文字
      ▼
  charging(7.0s) 蓄力，两部件逐渐靠拢，能量粒子汇聚
      │ 进度>30%：暗角渐显。血量越低蓄力越快（hpSpeedRatio 1.0→1.8）
      │ 蓄力完成：全场震碎玩家文字 + 画面震动 + 红色闪屏
      ▼
  attack         随机选择一个攻击模式（共三种）
    ├─ 偏旁冲撞：忄 高速飞向鼠标位置，碰边缘弹跳重定向
    ├─ 引力场 + 螺旋弹幕：右部件"感"制造引力漩涡，拖拽鼠标+持续发射螺旋弹幕
    └─ 心锁 + 雨弹幕：左部件"忄"锚定锁链，鼠标被困在锁圈内，正弦雨帘弹幕
      │ 弹幕类攻击持续N秒，期间非活动方部件消失
      ▼
  vulnerable(3.5s) 两部件合一，光环脉动+「破绽 · 1.5x」提示
      │ 玩家可点击攻字造成伤害，连击数正常工作
      ▼
  回到 split（如HP<50%：拆距加大/蓄力加速/暴露缩短 → 狂暴）

### 数值（按难度）
  HP: 简单400 / 标准800 / 困难1200
  蓄力: 7.0s / 暴露: 3.5s / 攻击冷却: 0.8s

  偏旁冲撞: 速度15(max 24) 伤害28 弹跳2次
  引力场弹幕: 螺旋 10发/波 速度1.6(max 2.8) 伤害10 持续6s 子弹间隔0.32s 引力强度0.7
  心锁雨弹幕: 正弦 6发/波 速度2.0(max 3.0) 伤害7 持续3.6s 锁圈半径180 子弹间隔0.42s

### 狂暴（HP<50%）
  拆距: 180 → 220
  蓄力: 7.0s → 5.0s
  暴露: 3.5s → 2.5s
  hpSpeedRatio: 1.0 → 1.8（攻速/蓄力速度随血量线性增长）

### Boss战连击
  攻击期有效命中Boss会累积连击数（x3/x5/x7里程碑音效）
  被弹幕/冲撞击中则连击清零
  其余与普通战斗连击规则一致


三、通用弹幕系统（projectile.js）
────────────

### Projectile 类
飞行文字弹体，带尾迹渲染、边界检测、鼠标碰撞检测。

### BulletPattern 生成器
  - radial(centerX, centerY, char, count, speed, ...) — 圆形扩散
  - spiral(...) — 螺旋旋转扩散
  - wave(...) — 正弦波浪下落

### executeAttack逻辑
  left_charge: 左部件飞向鼠标
  弹幕类（gravity_field / heart_lock / right_bullet）: 调用 BulletPattern 生成弹幕
  支持 hpSpeedRatio 加速（1.0~1.8），弹幕间隔由 bulletInterval 控制


四、Boss系统（boss.js）
────────────

### 状态机
  BOSS_PHASE: ENTRANCE | SPLIT | CHARGING | ATTACK | VULNERABLE | DEFEATED

### 核心函数
  initBoss(key)       — 初始化Boss（入场坠落动画），震碎玩家文字
  updateBoss(dt)      — 每帧状态更新 + 弹幕碰撞检测 + 引力场/心锁鼠标拖拽
  drawBoss(ctx)       — Canvas渲染（部件+HP条+引力漩涡+心锁锁链+弹幕+受击框）
  hitBossPart(mx,my)  — 返回{multiplier}：蓄力期0.8x / 暴露期1.5x
  damageBoss(dmg,mult)— 玩家伤害接口，仅蓄力/暴露期有效
  defeatBoss()        — 死亡演出（爆发粒子+两部件飘散+3秒后清场）

### 与战斗系统的交互
  - ENTRANCE/ATTACK/DEFEATED阶段：balanceWords不生成文字
  - SPLIT阶段：渐进恢复（_gradualRestore=6，每周期2词缓慢充盈）
  - CHARGING/VULNERABLE阶段：正常生成攻/防/愈/技能字
  - 攻字点击 → hitBossPart(mx,my) → 暴露期1.5x / 蓄力期0.8x / 其余无效
  - Boss战中普通敌人计时器暂停，隐藏普通敌人HP/计时条UI
  - Boss战中连击数正常工作，被弹幕击中清零

### 引力场渲染
  - 屏幕中央引力漩涡（三层扩散光环 + 径向辉光 + 中心"感"字）
  - 吸入粒子模拟物质被吞噬
  - 光标到中心的拉力光束可视化
  - 标签「引力场」显示在漩涡上方

### 心锁渲染
  - 锚点"忄"字 + 虚线锁链连接光标 + 边界圈
  - 接近边缘时闪烁警告（频率随距离加快）
  - 锁链上小粒子流动
  - 标签「心锁」显示在边界圈上方


五、鼠标受击框
────────────
仅在Boss攻击阶段显示——鼠标周围出现金色圆环。
弹幕/炮弹撞到圆环 → 玩家扣血（走applyDamageToPlayer，支持减伤/护盾/闪避）。
半径: 18px
